# 🏸 空間羽航員 V6.1 Stable

羽球社團自動輪轉排場工具。

## 功能

- 👥 球友名單管理
- 📋 名單匯入
- 🏸 自動公平排場
- 🔄 下一輪自動產生
- 🪑 休息分鐘累積
- 📊 今日統計
- 📱 手機版操作
- 🌐 GitHub Pages 支援

---

## 使用方式

1. 開啟網站
2. 加入今日球友
3. 設定球場數
4. 按開始排場
5. 每輪結束按「下一輪」

---

## 資料保存

本版本使用瀏覽器 LocalStorage 保存資料。

不需要登入。

不需要雲端。

資料保存在使用裝置中。
